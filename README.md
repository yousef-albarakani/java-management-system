# Java Management System

## Overview

A Java-based desktop management application developed using Object-Oriented Programming principles.

The system provides a graphical user interface for managing customers, appointments, services, payments, and staff operations.

## Features

- User Authentication
- Customer Management
- Appointment Management
- Service Management
- Payment Management
- Staff Dashboards

## Technologies

- Java
- Java Swing
- Object-Oriented Programming
- File-Based Data Storage
